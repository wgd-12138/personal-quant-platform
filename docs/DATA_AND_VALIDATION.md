# 数据获取与校验方案

## 数据原则

| 原则 | 要求 |
|---|---|
| 不造假 | 不允许用假行情、假新闻、假持仓、假收益 |
| 不补空 | 关键字段为空时直接失败 |
| 可追溯 | 每条结论能追到数据源和数据时间 |
| 可复查 | 每次运行保留原始数据摘要和报告 |
| 可对照 | 关键行情尽量使用两个来源交叉检查 |

## 数据源分层

| 数据 | 第一来源 | 第二来源 | 校验重点 |
|---|---|---|---|
| A 股板块 | 东方财富公开行情 | AkShare | 板块数、涨跌幅、成交额、主力净流入 |
| A 股个股 | 东方财富公开行情 | AkShare / Tushare | 价格、涨跌幅、成交额、换手、所属板块 |
| 指数环境 | 东方财富公开行情 | AkShare | 上证、深成指、创业板、科创、北证 |
| 外围市场 | 新浪财经美股历史 | 东方财富或交易所行情 | 纳指、半导体、AI、存储、台积电 |
| 持仓 | 本地 CSV | 后期券商接口 | 代码、名称、成本、数量、买入日期 |
| 新闻 | 东方财富 / 财联社网页源 | 巨潮公告 / 交易所公告 | 来源、时间、标题、匹配对象 |
| 解禁减持 | 巨潮 / 交易所公告 | Tushare | 日期、数量、占比、对象 |
| 产品价格 | 行业公开源 | 后期可接付费源 | 时间、单位、价格变化 |

## 数据新鲜度

| 场景 | 允许延迟 | 失败条件 |
|---|---|---|
| 盘中行情 | 5 分钟内 | 数据时间缺失或明显过期 |
| 外围日线 | 最近一个交易日 | 缺少关键标的超过 2 个 |
| 持仓 CSV | 用户手动维护 | 缺字段、数量为负、成本为空 |
| 新闻 | 24 小时内 | 无来源、无时间、无法匹配对象 |
| 晚间复盘 | 当天收盘后 | 没有当天市场数据 |

## 完整性校验

| 对象 | 最低要求 |
|---|---|
| 板块数据 | 不少于 300 个有效板块 |
| 个股数据 | 不少于 4000 个有效 A 股股票 |
| 外围指标 | 不少于 7 个当前可稳定验证的核心指标 |
| 持仓数据 | 每行必须有代码、名称、数量、成本价 |
| 新闻数据 | 每条必须有来源、时间、标题、链接或唯一标识 |

## 真实性校验

| 校验 | 规则 |
|---|---|
| 数值范围 | 涨跌幅、成交额、数量不能出现明显非法值 |
| 时间一致 | 报告日期、行情日期、新闻日期必须匹配 |
| 重复记录 | 同一股票或新闻重复时去重并保留来源 |
| 交叉验证 | 核心价格和涨跌幅与第二来源偏差过大时失败 |
| 缺口暴露 | 数据源不可用时报告失败，不生成“看起来正常”的报告 |
