# 产品需求说明

## 一句话目标

先在本地生成一份可以直接推送给个人使用的量化交易助手报告；确认内容稳定后，再接飞书、企业微信或其他推送渠道。

## 需求修正

| 问题 | 正确处理 |
|---|---|
| 之前只输出了行情总结 | 不够，必须补齐持仓、建仓、新闻、风险、复盘和次日计划 |
| 推送模块被放到后期 | 渠道可以后期，但“推送内容”必须现在就在本地报告里完整出现 |
| 建仓候选只看板块 | 不够，必须有选择逻辑、触发条件、失效条件和风险边界 |
| 持仓建议没出现 | 必须按每只持仓输出止盈、止损、减仓、补仓、清仓条件 |
| 新闻利好利空没出现 | 必须有来源、发布时间、匹配股票或板块、影响方向 |

## 用户每天真正需要看到的内容

| 场景 | 必须输出 | 不允许 |
|---|---|---|
| 盘中实时 | 热门板块、资金强弱、外围表现、今日操作建议 | 用空表或故事代替数据 |
| 持仓管理 | 每只持仓的止盈、止损、减仓、补仓、清仓建议 | 没有触发价、没有失效条件 |
| 建仓推荐 | 候选股、选择原因、买入触发、仓位上限、失败条件 | 没有主升也硬推股票 |
| 新闻捕捉 | 利好、利空、来源、时间、影响对象 | 只写“有消息刺激” |
| 晚间复盘 | 当天市场结论、强弱板块、失败方向、资金状态 | 只复读涨跌幅 |
| 次日计划 | 高开、低开、震荡、破位四种情景下的操作 | 单一方向猜测 |

## 报告类型

| 报告 | 触发时间 | 用途 | 第一版要求 |
|---|---|---|---|
| 盘中快照 | 手动运行，后续可定时 | 判断今天能不能动手 | 必须覆盖市场状态、热门板块、外围、今日建议 |
| 持仓建议 | 手动运行，后续盘中更新 | 管理已有仓位 | 必须读取真实持仓 CSV |
| 建仓候选 | 手动运行，后续盘中更新 | 找可试错目标 | 没有主升时明确输出暂无 |
| 新闻影响 | 手动运行，后续定时扫描 | 捕捉突发利好利空 | 每条新闻必须有来源和时间 |
| 晚间复盘 | 收盘后运行 | 总结当天，准备第二天 | 必须输出次日操作计划 |
| 数据质量报告 | 每次运行自动生成 | 防止假报告 | 数据缺失直接失败 |

## 盘中报告内容合同

| 模块 | 字段 |
|---|---|
| 数据质量 | 数据源、数据时间、板块数量、股票数量、外围数量、新闻数量、失败项 |
| 市场状态 | 指数涨跌、全市场成交、上涨家数、下跌家数、涨停数量、跌停数量、炸板率 |
| 热门板块 | 板块名称、今日涨幅、5 日涨幅、20 日涨幅、60 日涨幅、成交变化、主力净流入、上涨家数、标签 |
| 外围表现 | 纳指、费城半导体 ETF、英伟达、AMD、博通、美光、台积电；三星、SK 海力士、恒生科技等后续等稳定历史数据源再接入 |
| 今日建议 | 空仓、低仓、持仓不动、减仓、防守、可试错；必须给原因 |
| 主线判断 | 主升候选、反弹候选、高位兑现、一日游风险、无清晰主线 |

## 持仓建议内容合同

| 字段 | 说明 |
|---|---|
| 股票代码和名称 | 来自持仓 CSV 或券商接口，不能为空 |
| 成本价、现价、持仓数量 | 缺任一字段直接失败 |
| 浮盈浮亏 | 按真实成本和现价计算 |
| 所属板块状态 | 主升、反弹、高位兑现、一日游、弱势 |
| 操作建议 | 持有、减仓、补仓、清仓、观察 |
| 止损位 | 必须给价格或规则，例如跌破 5 日线且板块转弱 |
| 止盈位 | 必须给价格或规则，例如放量滞涨或跌破趋势线 |
| 减仓条件 | 必须是可验证条件 |
| 补仓条件 | 只有板块主升且个股重新转强才允许出现 |
| 清仓条件 | 必须覆盖破位、利空、放量下跌、板块退潮 |
| 利好利空 | 新闻来源、时间、标题、影响方向 |

## 建仓候选内容合同

| 字段 | 说明 |
|---|---|
| 候选股票 | 只能从主升候选板块里选 |
| 角色 | 龙头、中军、趋势核心、补涨，不混用 |
| 选择原因 | 板块强度、个股强度、成交放大、未高位透支 |
| 买入触发 | 价格、均线、突破、回踩、放量条件 |
| 失效条件 | 跌破关键位、板块退潮、成交萎缩、利好兑现 |
| 仓位上限 | 单票、单板块、总仓位限制 |
| 风险提示 | 解禁、减持、业绩兑现、龙虎榜异常、外围背离 |

## 晚间复盘内容合同

| 模块 | 必须回答的问题 |
|---|---|
| 今天市场如何 | 是主升、反弹、兑现、轮动，还是无主线 |
| 哪些方向最强 | 是否有持续性，是否只是单日脉冲 |
| 哪些方向失败 | 为什么失败，是利好兑现、缩量、还是高位拥挤 |
| 持仓怎么处理 | 第二天开盘、冲高、下杀、破位分别怎么做 |
| 明天看什么 | 关键板块、关键个股、关键价位、关键风险 |

## 建议语言边界

| 允许输出 | 禁止输出 |
|---|---|
| “满足条件后可小仓试错” | “一定会涨” |
| “跌破条件后应退出观察” | “闭眼买” |
| “暂无主升候选” | “为了有结果硬选股票” |
| “数据不足，无法判断” | “用 AI 编理由补齐” |
